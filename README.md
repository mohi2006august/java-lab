# 📝 Java Lab Manual - Notepad Edition

> **A Windows Notepad-camouflaged web app & complete repository for all 20 Java Lab Experiments.**  
> Built to look indistinguishable from **Windows 11 / Classic Notepad** on computer monitors during internal exams and lab sessions, equipped with 1-click fast copy, tabs, direct file saving, and viva cheat sheets.

🌐 **Live Web App**: [https://mohi2006august.github.io/java-lab/](https://mohi2006august.github.io/java-lab/)

---

## 🎭 The Ultimate Notepad Disguise

- **Windows Notepad Look & Feel**: Real title bar (`<filename>.java - Notepad`), window controls (`─`, `□`, `✕`), authentic menu bar (`File`, `Edit`, `View`, `Experiments`, `Lab Manual`), and Windows 11 style tabs!
- **Consolas Editor View**: Displays code with line numbers and authentic Notepad font formatting.
- **Both Dark & Classic Light Notepad**: Toggle seamlessly between Windows 11 Dark Notepad and Windows 10/Classic crisp white Notepad (`Alt+T` or `View > Theme`).
- **Collapsible File Explorer (`Ctrl+B`)**: Shows all 20 experiment files like an IDE or text editor project tree.
- **🚨 Double Panic Screen (<kbd>ESC</kbd>)**: If an invigilator approaches, press <kbd>ESC</kbd> to immediately disguise the screen as the official *Oracle Java™ SE 17 Platform Documentation*.

---

## ⚡ Fast Copy & Exam Cheats

- 📋 **Copy Code (<kbd>C</kbd>)**: Copies pure Java source code without markdown or clutter, ready to paste into any editor.
- 💾 **Save / Download .java (<kbd>Ctrl+S</kbd> or <kbd>D</kbd>)**: Instantly downloads the `.java` file with the exact required class name.
- ⚡ **Copy `javac` (<kbd>Alt+C</kbd>)**: Copies the exact compilation command.
- ▶️ **Copy `java` (<kbd>Alt+R</kbd>)**: Copies the execution command.
- 📥 **Copy Sample Input**: Copies the verified sample input.
- 🎓 **Viva Voce Panel (<kbd>Alt+M</kbd>)**: Slide out the Lab Manual panel containing the Aim, Instructor Notes, and viva questions with answers.

## 🌐 How to Enable GitHub Pages

1. Open your repository on GitHub: **[https://github.com/mohi2006august/java-lab](https://github.com/mohi2006august/java-lab)**
2. Go to **Settings** > **Pages**
3. Under **Branch**, select `main` and `/ (root)`
4. Click **Save**  
Your Notepad-styled cheat sheet will be live at:  
👉 **`https://mohi2006august.github.io/java-lab/`**
