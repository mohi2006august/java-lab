# Experiment 18: Word Frequency Count

## Aim
Write a Java program to count the frequency of each word in a given text.

## Compile Command
```bash
javac WordFrequency.java
```

## Run Command
```bash
java WordFrequency
```

## Sample Input
```
java is easy and java is powerful
```

## Sample Output
```
java: 2
is: 2
easy: 1
and: 1
powerful: 1
```

## Note
Punctuation is removed and words are counted without case sensitivity.

## Result
The program was executed and the output was verified.
