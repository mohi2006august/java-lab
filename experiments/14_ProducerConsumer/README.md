# Experiment 14: Producer–Consumer Using Inter-Thread Communication

## Aim
Write a Java program to implement the Producer–Consumer problem using inter-thread communication.

## Compile Command
```bash
javac ProducerConsumer.java
```

## Run Command
```bash
java ProducerConsumer
```

## Sample Input
```
(No input)
```

## Sample Output
```
Produced: 1
Consumed: 1
Produced: 2
Consumed: 2
...
Produced: 5
Consumed: 5
```

## Note
wait() and notifyAll() coordinate access to the shared buffer.

## Result
The program was executed and the output was verified.
