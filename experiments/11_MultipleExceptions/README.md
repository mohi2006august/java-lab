# Experiment 11: Handling Multiple Exceptions

## Aim
Write a Java program to handle multiple exceptions.

## Compile Command
```bash
javac MultipleExceptions.java
```

## Run Command
```bash
java MultipleExceptions
```

## Sample Input
```
10 0
1
```

## Sample Output
```
Cannot divide by zero
Program completed
```

## Note
Try inputs 10 2 5 to test the array-index exception separately.

## Result
The program was executed and the output was verified.
