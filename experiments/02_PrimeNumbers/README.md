# Experiment 2: Prime Numbers up to N

## Aim
Write a Java program to read an integer and print all prime numbers up to that integer.

## Compile Command
```bash
javac PrimeNumbers.java
```

## Run Command
```bash
java PrimeNumbers
```

## Sample Input
```
20
```

## Sample Output
```
2 3 5 7 11 13 17 19
```

## Note
Enter the upper limit N.

## Result
The program was executed and the output was verified.
