# Experiment 3: Fibonacci Using Recursive and Non-Recursive Methods

## Aim
Write a Java program to print the nth Fibonacci value using recursive and non-recursive functions.

## Compile Command
```bash
javac Fibonacci.java
```

## Run Command
```bash
java Fibonacci
```

## Sample Input
```
7
```

## Sample Output
```
Recursive: 13
Non-recursive: 13
```

## Note
This manual uses F(0) = 0 and F(1) = 1.

## Result
The program was executed and the output was verified.
