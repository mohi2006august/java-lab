# Experiment 13: Multithreading – Even Square and Odd Cube

## Aim
Create three threads: one generates a random integer every second; another prints its square if even; the third prints its cube if odd.

## Compile Command
```bash
javac ThreadDemo.java
```

## Run Command
```bash
java ThreadDemo
```

## Sample Input
```
(No input; generates 5 random numbers)
```

## Sample Output
```
Example output (will vary):
Number: 4
Square: 16
Number: 3
Cube: 27
```

## Note
This compact version uses a worker thread for each generated value. Random output changes on every run.

## Result
The program was executed and the output was verified.
