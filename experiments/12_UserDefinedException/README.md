# Experiment 12: User Defined Exception

## Aim
Write a Java program to create and use a user-defined exception.

## Compile Command
```bash
javac UserExceptionDemo.java
```

## Run Command
```bash
java UserExceptionDemo
```

## Sample Input
```
16
```

## Sample Output
```
Age must be 18 or above
```

## Note
Enter 18 or more to display Eligible.

## Result
The program was executed and the output was verified.
