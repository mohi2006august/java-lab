# Experiment 9: Abstract Class – Area of Shapes

## Aim
Create an abstract class Shape with printArea(). Extend it using Rectangle, Triangle and Circle.

## Compile Command
```bash
javac ShapeDemo.java
```

## Run Command
```bash
java ShapeDemo
```

## Sample Input
```
5 4
6 3
2
```

## Sample Output
```
Rectangle area: 20.0
Triangle area: 9.0
Circle area: 12.566370614359172
```

## Note
Input order: rectangle length and breadth, triangle base and height, then circle radius.

## Result
The program was executed and the output was verified.
