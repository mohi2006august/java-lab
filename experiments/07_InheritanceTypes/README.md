# Experiment 7: Types of Inheritance

## Aim
Write a Java program to illustrate single, multilevel and hierarchical inheritance.

## Compile Command
```bash
javac InheritanceDemo.java
```

## Run Command
```bash
java InheritanceDemo
```

## Sample Input
```
(No input)
```

## Sample Output
```
Animal eats
Dog barks
Animal eats
Dog barks
Puppy weeps
Animal eats
Cat meows
```

## Note
Dog demonstrates single inheritance, Puppy demonstrates multilevel inheritance, and Dog/Cat demonstrate hierarchical inheritance.

## Result
The program was executed and the output was verified.
