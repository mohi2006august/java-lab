# Experiment 17: Read Integers and Find Sum

## Aim
Read a line of integers and display each integer and their sum.

## Compile Command
```bash
javac IntegerSum.java
```

## Run Command
```bash
java IntegerSum
```

## Sample Input
```
10 20 30 40
```

## Sample Output
```
10
20
30
40
Sum: 100
```

## Note
Enter all integers on one line separated by spaces.

## Result
The program was executed and the output was verified.
