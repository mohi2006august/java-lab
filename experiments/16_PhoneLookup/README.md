# Experiment 16: Hash Table – Name and Phone Lookup

## Aim
Load tab-separated names and phone numbers from a text file and search by either value using a hash table.

## Compile Command
```bash
javac PhoneLookup.java
```

## Run Command
```bash
java PhoneLookup
```

## Sample Input
```
Ravi
```

## Sample Output
```
9876543210
```

## Note
Create contacts.txt in the same folder. Example line: Ravi<TAB>9876543210. Search using either the name or phone number.

## Result
The program was executed and the output was verified.
