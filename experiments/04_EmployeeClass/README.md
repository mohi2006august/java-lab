# Experiment 4: Employee Class Using Constructor and Method

## Aim
Create an Employee class to read and display employee ID, name, department, salary and experience using a constructor and method.

## Compile Command
```bash
javac EmployeeDemo.java
```

## Run Command
```bash
java EmployeeDemo
```

## Sample Input
```
101
Asha Rao
CSE
45000
2
```

## Sample Output
```
101 Asha Rao CSE
Salary: 45000.0
Experience: 2 years
```

## Note
Enter values in the order shown: id, name, dept, salary, experience.

## Result
The program was executed and the output was verified.
