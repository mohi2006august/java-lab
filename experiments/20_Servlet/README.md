# Experiment 20: Hello World Servlet Using Tomcat

## Aim
Install and configure Tomcat and deploy a simple Hello World servlet.

## Compile Command
```bash
javac -cp servlet-api.jar HelloServlet.java
```

## Run Command
```bash
Deploy to Tomcat /webapps and access http://localhost:8080/YourApp/hello
```

## Sample Input
```
Open in browser: http://localhost:8080/YourApp/hello
```

## Sample Output
```
Hello World from Servlet
```

## Note
This example uses Jakarta Servlet imports (Tomcat 10+). Compile/deploy with the matching Servlet API and place the application under Tomcat webapps, or deploy a WAR.
