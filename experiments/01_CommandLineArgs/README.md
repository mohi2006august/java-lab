# Experiment 1: Command Line Arguments

## Aim
Write a Java program to accept Student Name and Roll Number as command-line arguments and display them.

## Compile Command
```bash
javac StudentDetails.java
```

## Run Command
```bash
java StudentDetails Ayush 25911A66D6
```

## Sample Input
```
java StudentDetails Ayush 25911A66D6
```

## Sample Output
```
Student Name: Ayush
Roll Number: 25911A66D6
```

## Note
Compile using javac StudentDetails.java, then pass the name and roll number after the class name.

## Result
The program was executed and the output was verified.
