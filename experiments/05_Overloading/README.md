# Experiment 5: Method and Constructor Overloading

## Aim
Write a Java program to illustrate method overloading and constructor overloading.

## Compile Command
```bash
javac OverloadDemo.java
```

## Run Command
```bash
java OverloadDemo
```

## Sample Input
```
(No input)
```

## Sample Output
```
Default constructor
Value: 10
Integer sum: 9
Double sum: 6.0
```

## Note
Different parameter lists allow Java to select the matching constructor or method.

## Result
The program was executed and the output was verified.
