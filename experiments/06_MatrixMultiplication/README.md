# Experiment 6: Matrix Multiplication Using Objects

## Aim
Write a Java program to multiply two matrices by passing objects as parameters.

## Compile Command
```bash
javac MatrixMultiply.java
```

## Run Command
```bash
java MatrixMultiply
```

## Sample Input
```
2 2
1 2
3 4
2 2
5 6
7 8
```

## Sample Output
```
19 22
43 50
```

## Note
Enter rows and columns, followed by matrix elements. The number of columns of the first matrix must equal the rows of the second.

## Result
The program was executed and the output was verified.
